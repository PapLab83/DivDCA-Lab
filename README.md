# DivDCA-Lab

---

## Архитектура DivDCA Lab

Прототип построен по модульному принципу, разделяя ответственность (SOLID). Каждый модуль решает свою задачу, что позволяет легко тестировать, расширять и заменять компоненты.

### Модули (Layers)

#### 1. **Data Layer (Слой данных)**
   - **Задача:** Получение, валидация и сохранение исторических данных по акциям.
   - **Компоненты:**
     - **`HistoricalDataFetcher`** (Абстрактный класс/Интерфейс): Определяет контракт для получения данных (тикер, дата начала, дата окончания).
     - **`LocalJsonDataProvider`** (Реализация): Читает предварительно сохранённые JSONL-файлы с историей цен и дивидендов.
     - **`DataValidator`**: Проверяет целостность и полноту загруженных данных.
   - **Формат хранения:** `{TICKER}_{START_YEAR}_{END_YEAR}.jsonl` (JSON Lines). Каждая строка — объект с полями: `date`, `price`, `div_annual`, `reason_short`, `reason_long`.

#### 2. **Analytics Engine (Вычислительное ядро)**
   - **Задача:** Расчёт всех метрик для стратегии DCA на основе загруженных данных.
   - **Компоненты:**
     - **`PortfolioSimulator`**: Принимает `DataFrame` с историей и параметры симуляции (`start_date`, `annual_investment`). Рассчитывает пошагово:
       - Количество купленных акций каждый год.
       - Накопленные показатели: `total_invested`, `portfolio_value`, `total_div_received`, `net_result`.
       - Усреднённую цену входа (`avg_cost`), доходность на成本 (`yield_on_cost`).
     - **`MetricCalculator`** (Абстракция): Интерфейс для расчёта отдельных метрик (например, `CagrCalculator`, `TotalReturnCalculator`). `PortfolioSimulator` использует набор таких калькуляторов.
     - **`DCAStrategy`**: Класс, инкапсулирующий логику усреднения (покупка на фиксированную сумму) и хранения состояния портфеля на каждом шаге.

#### 3. **Visualization & Reporting (Визуализация и отчёты)**
   - **Задача:** Генерация наглядных графиков и итоговых отчётов.
   - **Компоненты:**
     - **`ReportGenerator`**: Преобразует результат `PortfolioSimulator` в сводный `DataFrame` и структурированный словарь для визуализации.
     - **`HtmlReportBuilder`**: Создает интерактивный HTML-отчёт с использованием Plotly. Генерирует ключевые графики:
       1. Динамика цены и дивидендов.
       2. Рост портфеля и вкладов (`total_invested` vs `portfolio_value`).
       3. Компоненты доходности (прирост капитала vs дивиденды).
       4. Динамика `net_result` (чистая прибыль/убыток).

#### 4. **Orchestrator (Координатор)**
   - **Задача:** Связывает все модули, управляет выполнением сценариев.
   - **Компоненты:**
     - **`AnalysisOrchestrator`**: Главный координатор. Выполняет пайплайн: `Загрузка данных` → `Симуляция` → `Формирование отчёта` → `Сохранение результатов`.
     - **`ScenarioRunner`**: Утилита для запуска и сравнения нескольких сценариев (например, DCA с 2000 года vs DCA с 2010 года).

### Поток данных (Data Flow)
```
[Local JSONL Files] → Data Layer (LocalJsonDataProvider) → [DataFrame]
     ↓
[DataFrame + Параметры] → Analytics Engine (PortfolioSimulator) → [Result Object]
     ↓
[Result Object] → Visualization (HtmlReportBuilder) → [HTML Report]
```
