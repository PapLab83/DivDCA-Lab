Приложение "Тестирование БД"

1) в гитхабе создать тестовый проект для обкатки
2) создать .env файл с параметрами подключения к БД (добавить .env.example в репо)
3) используя docker compose запустить контейнер с PostgreSQL
4) используя стек: Python, Alembic, SQLAlchemy, Docker:
  
  Подготовка:
  - описать таблицу с 3-4 столбцами и составным PRIMARY KEY через SQLAlchemy
  - создать миграцию через Alembic и применить
  
  Функции работы с данными:
  - реализовать функцию data_load_to_db (с поддержкой bulk insert и обработкой конфликтов)
  - реализовать функцию data_unload_from_db (выгрузка в список словарей)
  
  Эксперименты:
  - сгенерировать моковые данные (100-1000 записей) с уникальным составным ключом
  - загрузить данные в таблицу через data_load_to_db
  - добавить 1-2 столбца через Alembic, заполнить новые колонки значениями
  - удалить один столбец через Alembic
  
  Выгрузка данных:
  - выгрузить данные через data_unload_from_db в:
    * список словарей
    * pandas DataFrame
    * JSON-файл
    * CSV-файл
  
  Бэкап и восстановление:
  - сделать бэкап БД через pg_dump (сохранить в ./backups/)
  - восстановить БД из бэкапа в чистую БД
  - проверить целостность данных (количество записей, контрольную сумму)
  
  Очистка:
  - реализовать скрипт cleanup.py для полной очистки
  
  Документация:
  - написать README.md с инструкцией по запуску
  - автоматическое бэкапирование (опционально, звездочка)

Требования:
- таблицы создавать только через SQLAlchemy + Alembic
- для загрузки/выгрузки использовать вспомогательные функции
- моковые данные генерировать отдельным скриптом
- для запуска БД использовать docker compose
- параметры подключения хранить в .env
- код должен быть задокументирован (docstrings)
